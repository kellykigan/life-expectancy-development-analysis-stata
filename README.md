# Life Expectancy and Development Indicators: Stata Analysis

## Project Overview

This project demonstrates a reproducible quantitative data analysis workflow using Stata. The analysis explores relationships between life expectancy and selected development indicators across countries between 2000 and 2015.

The project focuses on practical quantitative research skills including data management, data cleaning, descriptive analysis, visualization, missing data assessment, variable transformation, and panel data preparation.

## Dataset

The dataset contains country-level observations from 2000 to 2015 and includes variables related to health, education, economic development, and demographic conditions.

The dataset contains 2,938 country-year observations across 193 countries.

Key variables include:

- Life expectancy
- Adult mortality
- Infant deaths
- HIV/AIDS mortality
- GDP per capita
- Years of schooling
- Income composition of resources
- Immunization indicators
- BMI
- Population
- Country development status

## Research Focus

The analysis investigates relationships between life expectancy and selected development indicators, including:

- Schooling
- GDP per capita
- Adult mortality
- HIV/AIDS mortality
- Development status

## Skills Demonstrated

### Data Management

- Importing CSV data into Stata
- Inspecting dataset structure
- Renaming variables
- Applying variable labels
- Creating numeric country identifiers
- Saving prepared datasets

### Data Quality Assessment

- Checking missing values
- Identifying duplicate observations
- Validating country-year uniqueness
- Checking plausible value ranges
- Investigating missing data patterns

### Descriptive Analysis

- Summary statistics
- Group comparisons
- Cross-tabulations
- Distribution analysis

### Data Visualization

- Box plots
- Scatter plots
- Linear fitted plots
- Histograms

### Data Transformation

- Creating missingness indicators
- Log-transforming GDP per capita

### Panel Data Preparation

- Creating country identifiers
- Declaring panel data using `xtset`
- Examining panel structure using `xtdescribe`
- Examining within and between variation using `xtsum`
